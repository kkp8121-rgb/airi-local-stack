## 1. 반드시 알아야 할 정정 3건

### 1-1. s2-r2·s3-r2 는 사람 전수 채점이 아니다

사용자 확인(2026-08-27): 두 회차의 `airi-human-rating.json` 은 **AI 가 채점하고 사용자가 읽고
승인**한 것이다. 반면 기준선 run 04 와 06b-r3 는 사용자가 시트에서 직접 채점했다(다운로드 원본
바이트 크기 일치, AI 초안과 5축 완전일치 6.1% / 0.0%).

→ **기준선과 후보가 다른 자로 측정됐다.** 사람 채점 회차에서 잰 AI−사람 편차는 회차마다 부호가
뒤집힌다(+0.15 / −0.31). 기존 기록의 "99/99턴 사람 채점" 은 s2/s3 에 한해 그렇게 읽어야 한다.

### 1-2. 3.0 게이트는 이 입력에서 도달 불가능하다

사용자가 직접 채점한 198턴에서 `context_retention` 평균 **1.54**, **4점 이상 0건**. 이 축이 3축
합성의 1/3 이므로:

> 3.0 을 넘으려면 나머지 두 축이 평균 **3.73** 이어야 한다 — 실측(1.98)의 1.9배.
> 맥락 유지가 관측 상한 3.0 까지 올라도 나머지가 3.00 은 되어야 한다.

모델을 고쳐도 넘지 못한다. **S3 `[x]` 는 PASS 도 FAIL 도 아닌 측정 불가**이고, S2 `[F]` 와 기준선
1.7576 도 같은 입력 위의 값이다.

원인은 두 겹이다. ①입력에 스레드가 없다 — 네 회차 모두 99턴에 시청자 **96명**, 재발화 3%,
AIRI 답 이어받기 3%. ②더 근본적으로 **채팅이 AIRI 에게 온 것이 아니다** — 인사 의식·내부 농담은
다른 스트리머와 그 커뮤니티의 관계 산물이다. 인사 밈이 픽업의 12% / 10% 를 차지했다.

**S3-r2 사람 재채점(30턴)은 사용자 결정으로 취소됐다.** 더 정밀하게 재는 것은 "못 넘는다" 를 더
정확히 재는 일일 뿐이다.

### 1-3. 픽업 처방이 실측으로 기각됐다

같은 문서 §4 는 "`reaction` 이 우선순위 6/7 이라 승격하면 된다" 로 끝났다. **틀렸다.**

공개 VOD 1편에서 **실제 스트리머가 반응한 채팅 57건**을 정답지로 만들어 대조한 결과:

| 변형 | 픽업 | 정답 적중 | 적중률 |
|---|---|---|---|
| 현행 | 77 | 4 | **7.0%** |
| `reaction` 승격 | 77 | **0** | **0.0%** |
| `turn_cooldown` 10s | 128 | 3 | 5.3% |
| `pending_stale` 300s | 77 | 2 | 3.5% |

그리고 스트리머가 반응한 57건 중 **80.7% 가 question 이 아니다**(질문 선호는 1.7배뿐). 현행 정책은
픽업 77건 중 75건을 질문으로 채운다.

원인은 `choose_pickup` 이 **엄격한 순위 + 선착순**이라는 것이다. 리액션을 올리면 4,662건 백로그의
**가장 오래된 것**부터 읽는다. **순위의 순서가 아니라 그 구조가 문제**이므로 설정 노브로 닫히지
않는다.

**점수제도 답이 아니다(이식해서 측정함).** `chat_replay` 의 점수 체계를 `broadcast_sim` 에 기본 OFF
greybox(`fixture.pickup_policy="scored"`)로 이식하고 가중치는 원본 그대로 옮겼다. 결과는 최고
**8.8%(5건) vs 현행 7.0%(4건)** — 하한 정답지에서 1건 차이는 의미가 없고, **모든 변형이 질문
100%** 다. 초당 2.8건이라 5초 창에 질문이 1.5건 들어오는데 질문 80점 대 리액션 최대 21점(3.8배)
이라 질문이 하나만 있어도 끝나기 때문이다. **실측된 스트리머의 질문 선호는 1.7배**이므로 가중치
격차가 실제의 두 배 넘게 과하다. 1.7배로 맞추면 그것이 곧 57건 피팅이라 중단했다.

→ **픽업 트랙은 종료한다.** 구조를 통째로 바꿔 얻은 것이 1건이고, 완벽히 고쳐도 목표가 "남의
커뮤니티 인사에 잘 답하기" 가 된다. 점수제는 기본 OFF 로 남아 있으니 입력이 바뀌면 다시 재면 된다.

3. 지식 2차 배치가 필요하면 계약서 §7 프롬프트에 주제만 채워 돌린다. 회수율은
   `knowledge_batch.py probe --min-hit-rate` 로 게이트할 수 있다.

**픽업 트랙은 종료했다(§1-3).** 재개하지 말 것.
