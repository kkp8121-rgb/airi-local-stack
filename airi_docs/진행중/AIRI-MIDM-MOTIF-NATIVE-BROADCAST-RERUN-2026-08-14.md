# AIRI Mi:dm–Motif native 방송 재실행 — 2026-08-14

## 판정 범위와 대체

이 문서는 **Mi:dm native 대 Motif native**만 재실행한 기록이다. 이전 Motif native/common 결론은 singular-EOS override와 이전 대화에서 유래했을 우려가 있는 fixture라는 두 결함 때문에 방법론적으로 무효이며, 이 기록으로 대체한다. common 경로나 타 후보의 우열을 이 결과로 주장하지 않는다. 사람 점수·최종 품질 승자는 아직 **보류**이며, 수치 점수를 만들어 내지 않았다.

16개는 wholly new, generic, synthetic live-broadcast fixture다. 금지된 이전 대화 용어는 0건이고, 두 모델의 case/run별 직렬화 message SHA-256은 64/64 정확히 일치했다(16 case × hf_card 1회 + broadcast_equal 3회 = 모델별 64회).

## 사람 검수 전의 관찰과 운영 권고

이는 원문에서 확인되는 비수치 관찰이며 사람 품질 점수는 아직 없다. Mi:dm은 빠르지만 game_reaction·dead_air·ambiguous_chat에서 문맥 밖 응답/환각, unsupported_boast에서 모델 정체성 드리프트, tactics와 conflicting_chat의 실패가 보인다. Motif는 short_memory·tactics·harassment/privacy에서 더 일관된 문맥·전술·안전 응답을 보였으나 느리고 장황하다. Motif도 ambiguous_chat 환각, audio_issue와 unknown_patch의 근거 없는 현재/오디오 주장, spoiler 경계 약점이 있다.

따라서 이 재실행만으로 어느 쪽도 자동 최종 승자가 아니다. 인간 검수가 품질을 결정할 때까지 Mi:dm은 latency 때문에 운영 baseline으로 유지한다. Motif는 별도로 라이선스가 deployment-blocked 상태이므로, 품질 판단과 무관하게 배포 후보가 아니다.
