## 3. 읽기

1. **S0 — n=1은 무의미하다.** 같은 구성 4회에서 "?" 종결이 15~84, "음" 오프너가 1~89로 흔들린다(SD ≈ 30/99). 붕괴는 run 단위로
   일어나거나 안 일어나는 쌍봉 현상이다. 08-19 이후의 모든 단일 run 비교(합성 매트릭스 포함)와 run 04→05 비교는 이 노이즈 안에 있다.
   앞으로 후보 비교는 복제 ≥3의 **붕괴 빈도·분포**로 읽고, 사람 채점은 사전 등록 규칙으로 고른 1회만 한다.
2. **S1 — 되먹임 고리는 붕괴의 증폭기이지 원인이 아니다.** 되먹임 채널은 셋이었다: (a) foreground 투영이 5어절 이하 채팅에서 '?'가
   든 직전 AIRI 응답을 유지, (b) journal 회수의 assistant 행, (c) 하니스 브리핑 "방금 흐름 → 나: <직전 응답>"(`broadcast_sim.py:520-525`).
   셋을 다 끊으면 템플릿 고정("음... 뭐가 X인데?")은 0/3으로 사라지고 완전 에코도 0이 된다. 그러나 자기 출력을 전혀 보여주지 않아도
   **문구 고정이 2/3**에서 생긴다(§2-1). 되먹임은 모델이 이미 내놓은 저품질 문형을 잠그는 역할이었고, 문형 자체는 프롬프트 형태
   (맥락 없는 짧은 채팅 + 비트 큐)에 대한 모델의 저엔트로피 기본 응답이다.
3. **S1은 사람 채점에서도 채택 기준에 못 미쳤다(§2-3).** 3축 1.90(+0.14)으로 참고 채점(1.59)보다는 낫지만 +0.2 미만이고 filler는
   55.6%로 늘었다. 실패 모드가 "되묻기"에서 "질문 무시 + 비트 큐 되풀이"로 바뀌었고, 말투·사실성·치명률만 좋아졌다. 운영 flag on
   요청은 내지 않는다. 채점 대상은 사전 등록대로 `06b-r3`였고 run 05 시트는 미채점으로 남아 있다(대조군 확정은 선택).
4. **입력 자체의 문제가 드러났다.** 재생 채팅은 원 방송의 화면·행동(모션 트래커, 춤, 링피트, 장갑…)에 대한 반응이고, fixture는
   "저스트 채팅 수다"다. "장갑은 왜 끼는거임?"·"풀트로 춤이라도 춰?"는 화면 맥락 없이는 어떤 모델도 답할 수 없다. 99턴 중 자기완결적
   질문은 소수이며, 사람 기준선 1.76의 상당 부분은 모델이 아니라 이 불일치를 재고 있다. 방송다움을 재려면 (a) 자기완결적 저챗
   구간을 고르거나, (b) VOD의 스트리머 발화(로컬 STT)를 시간 정렬해 "AIRI가 방금 한 말"로 공급해 시청자 반응이 성립하게 해야 한다.
