기존 기록(`AIRI-WORKING-STATE.md` s2_note/matrix_note, `AIRI-ROADMAP-LOG.md` 2026-08-26 항목)의
"99/99턴 사람 채점" 표현은 s2-r2·s3-r2에 한해 **"AI 채점 99턴 + 사용자 승인"으로 읽어야 한다.**
승인 자체는 사용자의 판단이므로 무효가 아니지만, 아래 세 가지가 따라온다.

### 1.1 AI 채점 절차 간 편차가 1.0점이다

같은 s3-r2 99턴에 앵커 캘리브레이션(사람 채점 198턴)과 시청자 페르소나를 주고 독립 채점시킨 결과:

| 채점자 | 3축 | 승인값(3.0976) 대비 |
|---|---|---|
| codex-calibrated-viewer | 1.9798 | −1.1178 |
| claude-calibrated | 2.1145 | −0.9832 |
| 두 AI 상호 차이 | — | **0.1347** |

두 AI 는 서로 0.09~0.13 안에서 일치(턴 단위 ±1 이내 88.9~96.0%)하면서 승인값과는 1.0 떨어졌다.
**AI 채점은 프롬프트·프라이밍에 따라 게이트 기준선을 통째로 건너뛸 만큼 이동한다.**

### 1.2 기준선과 후보가 다른 자로 측정됐다

사람 채점 회차에서 잰 AI−사람 편차는 회차마다 **부호가 뒤집힌다**: replay-04 +0.1515, 06b-r3 −0.3131.
기준선은 사람 자, s2·s3는 AI 자이므로 이 ±0.3 이 그대로 비교에 실린다.

### 1.3 S3 의 PASS 는 지지되지 않는다

| 항목 | 값 |
|---|---|
| 기준선 3.0 대비 여유 | **+0.0976** |
| 99턴 표본 표준오차 | ±0.0885 (95% 구간 [2.9241, 3.2712] — 3.0 을 가로지름) |
| 자 차이에서 오는 불확실성 | ±0.3 |

여유 0.0976 에 불확실성 0.3 이다. 다른 회차는 −7.59σ ~ −14.53σ 로 확고한데 **s3-r2 만 +1.10σ** 다.
S3 의 `[x]` 채택은 "S3 가 좋았다"가 아니라 **"그 회차를 어떤 채점자가 쟀는가"**의 결과일 수 있다.

### 1.4 진행 중인 확인

사용자가 s3-r2 를 직접 채점해 눈금을 확정하기로 했다(2026-08-27). 층화 30턴 중 **2턴 완료**
(turn 19, 30). 관측 오프셋 +0.1667, 잔차 SD ≈ 0.7 → 그 SD 가 유지되면 **총 22턴**에서 95% 구간이
3.0 위로 확정된다. 다만 오프셋이 0 근처로 나오면 99턴 전수로도 구간이 3.0 을 가로질러 **판정 보류**가
정직한 결론이 된다. 남은 턴 시트는 어느 지점에서 멈춰도 표본이 치우치지 않도록 사분위 라운드로빈으로
배치했다(저장소 밖 회차 디렉터리).

## 2. 코멘트 분석 — 점수가 버리는 정보 (198턴)

센다)"가 설계다. 그런데 사용자가 직접 채점한 두 회차는 **99/99턴 전부에 코멘트**가 달려 있고, 그것이

키워드 분류이므로 미분류 33.8% 가 남는다. 범주 체계를 제대로 뽑으려면 198건 정독이 필요하다.

### 2.1 점수는 "얼마나 나쁜가"만 말하고 "왜 나쁜가"를 못 말한다

템플릿 오발동 1.41, 폴백 1.10, 안전 사고 1.41 — **점수가 사실상 같은데 요구되는 수리는 전부 다르다.**
3축 합성 하나로 뭉치면 어디를 고쳐야 하는지가 사라진다.

### 2.2 로드맵 조준점 문제

- **지식 결함 7건**은 파인튜닝으로 안 고쳐진다. 특정 콘텐츠·슬랭을 모르는 것이므로 지식 주입 문제다.
- **템플릿 오발동 35건**은 결정론 계층 결함이지 모델 문제가 아니다.
- 둘을 합쳐 **42건(21.2%)이 P3 학습 트랙이 손댈 수 없는 영역**이다.

### 2.3 성공 사례 13건이 학습에 안 쓰이고 있다

사용자가 "정답 모드"로 직접 지목한 실제 발화 13건(평균 3축 3.62)이 있는데, 학습 트랙은
`synthesize_behavior_pending.py` 의 **합성 정답**을 쓴다. 검증된 실제 정답이 유휴 상태다.

### 2.4 코멘트에만 있는 버그 리포트 8건

가명(`v`+8자)이 출력에 그대로 노출된 턴, 문장 중간 절단, 어휘 오기 등. 점수가 아니라 이슈 티켓이며
현재 어떤 추적도 되지 않는다. 해당 turn_no: replay-04 10·17·21·34·39·65, 06b-r3 48·76.

### 2.5 계약의 미완 조항

계약 §1 은 "원 방송 맥락에 묶인 메시지가 섞이므로 채점 시 '원 방송 맥락 의존' 코멘트로 구분한다"고
하지만 **구분한 뒤 무엇을 하라는 규정이 없다.** 무효 문항을 집계에 그대로 넣으면 AIRI 가 볼 수 없는
맥락에 대한 실패가 점수에 실린다.

## 3. 제안 (미승인)

1. 채점 시트에 **턴별 사유 분류를 구조화 필드로** 추가하고 `summarize_ratings.py` 가 집계한다.
   자유 코멘트는 유지하되, 범주는 기계가 읽을 수 있어야 한다.
2. **무효 문항은 집계에서 분리**한다(계약 §1 의 뒤를 채운다).
3. **정답 모드 턴을 학습 정답 후보로 수집**하는 경로를 만든다.
4. **출력 버그는 채점이 아니라 이슈로** 뺀다.
5. 198건 정독으로 범주 체계를 확정한다(현재 키워드 분류는 미분류 33.8%).
