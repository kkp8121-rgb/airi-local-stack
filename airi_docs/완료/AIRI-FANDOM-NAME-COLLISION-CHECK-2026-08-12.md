# AIRI 팬덤명 “아이리스” 공개 충돌 검토 (2026-08-12)

## 판정

팬덤명 **“아이리스”의 공개 사용은 FAIL**이다. 일반 사전어라는 사실보다
동일 엔터테인먼트·버추얼 크리에이터 검색면의 현역 충돌이 핵심이다. AIRI
캐릭터명은 유지하되 팬덤명은 데뷔 전에 다시 선택한다. 이 검토는 공개 명칭의
식별력·검색 혼동 판정이며 상표권 법률 의견이 아니다.

## 확인된 충돌

| 대상 | 확인 사실 | 위험 |
|---|---|---|
| Hololive English `IRyS` | [공식 talent 페이지](https://hololive.hololivepro.com/en/talents/irys/)의 현역 버추얼 탤런트. [2026년 첫 단독 콘서트](https://hololive.hololivepro.com/events/hope-beyond-the-stars/)가 있으며 공식 팬명은 `IRyStocrats`다. [한국어권 콘텐츠](https://www.youtube.com/watch?v=BV-DTLf8lY8)에서는 `IRyS`를 “아이리스”로 표기한다. | **높음** — 같은 VTuber 시청자·검색어. 팬덤명 자체의 정확 일치는 아니지만 AIRI/아이리스 조합의 출처 혼동이 크다. |
| 한국 인터넷 방송인 `@anyiris` | [공식 YouTube 채널](https://www.youtube.com/@anyiris)의 표시명이 정확히 “아이리스”다. | **높음** — 국내 인터넷 방송 검색면의 정확 일치. |
| K-pop 그룹 `IRRIS` | JUSTICE RECORDS의 [공식 MV](https://www.youtube.com/watch?v=HfRa3Jfy__Q)와 [KBS 프로필](https://kstar.kbs.co.kr/person_view.html?idx=216963)이 `IRRIS (아이리스)`를 사용한다. | **중~높음** — 음악·팬덤·굿즈 검색면의 정확 한글 일치. |
| 한예슬 팬클럽 | 2004년 [창단 보도](https://www.starnewskorea.com/broadcast-drama/2004/09/07/2004090709305610932)에 공식 팬클럽명이 정확히 “아이리스”로 기록됐다. | **중간** — 현재 운영 여부는 확인하지 못했지만 정확 팬덤명 선사용 기록이다. |

드라마·화장품·기업 등 비엔터테인먼트 동명도 다수라 검색 식별력은 더 낮다.
위 네 건만으로도 “충돌 없음” 판정은 불가능하며, 단독 표기·해시태그·굿즈
명칭으로 채택할 이유가 없다.

## 후속 gate

1. “아이리스”는 문서의 확정 팬덤명에서 철회하고 사용자 재선정 항목으로
   되돌린다. 과거 결정 로그는 당시 기록으로 보존한다.
2. 새 후보는 한글 exact 검색, 로마자 표기, YouTube/치지직/X 해시태그를
   다시 확인한 뒤 확정한다.
3. 유료 굿즈·채널 멤버십 전에 [KIPRIS](https://www.kipris.or.kr/)에서
   관련 상품·서비스류의 동일·유사 상표를 별도로 확인하고 필요하면 변리사
   검토를 받는다. 이번 공개 웹 검토는 상표 등록 가능성을 증명하지 않는다.
