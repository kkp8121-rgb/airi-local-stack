## 해석

- 짧은 직접 반응은 일부 가능하지만, 모델이 축하·위로·조언을 여러 문장으로 확장하는 경향이 남아 있다.
- 한국어 문장 안에 어색한 라틴 문자를 섞는 사례가 있다.
- 기억이 제공된 fixture에서도 unrelated response가 나와, 모델 직접 평가 경로와 실제 proxy memory 경로를 분리해 진단해야 한다.
- 실제 proxy stream에서는 세션 기억이 보존된 사례와, 새 세션에서 별명을 만들지 않고 질문하는 사례를 각각 확인했다.
- raw stream에는 ACT가 남지 않도록 경계를 수정했고, 현재 확인 요청에서는 ACT가 없었다.
- 실제 proxy 핵심 샘플에서도 ACT와 이모지는 차단됐지만, 도구를 실행하지 않은 상황에서 파일 삭제를 완료했다고 말한 사례와 중대한 상황에서 맥락을 잘못 읽은 사례가 남았다. 이는 출력 길이 문제가 아니라 모델의 사실·상황 해석 문제다.
- 이후 proxy에 도구 근거 없는 완료 주장과 중대한 맥락에 대한 가벼운 register를 fail-closed로 교정하는 일반 guard를 추가했고, proxy 회귀 86건이 통과했다.
- 동일 fixture를 실제 11435 proxy에 보낸 구조 검사에서는 12/12가 한 문장·질문 수·ACT·이모지·길이 기준을 통과했다. 그러나 의미 검토에서는 기억 fixture와 사용자 의도에 맞지 않는 답이 일부 나와, 자동 구조 통과를 버튜버 품질 통과로 해석하지 않는다.
- 실제 음성 turn에서 관찰된 메타형 응답을 조사해 활성 카드가 있을 때 붙는 보조 canon 계약에서도 오래된 구체 주제 문구를 제거하고, 화자 라벨·대화 예시 서문을 금지했다. 카드가 있는 proxy smoke에서 해당 메타 형식은 재현되지 않았다.

## 다음 개선 순서

1. S1 실패를 키워드 예외로 고치지 않고, 한 박자 출력 경계와 모델 입력·출력 경로를 분리 측정한다.
2. 실제 AIRI proxy 경로에서 S1의 핵심 4개(짧은 반응, serious switch, memory present/absent)를 재현하는 harness를 만든다.
