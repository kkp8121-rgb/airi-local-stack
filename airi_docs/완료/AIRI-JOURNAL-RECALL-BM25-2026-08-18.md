# journal recall 어휘 스코어링 — FTS5 bm25() 도입 (2026-08-18, 클로드 PC)

> 리서치 실행 로드맵 ①(`참조/AIRI-MEMORY-TECH-RESEARCH-2026-08-18.md` §3)
> 이행. 자체 레포 감사가 지목한 "유일하게 살아있는 회상 경로의 결함"을
> 닫는다. 의존성 추가 0·스키마 변경 0.

## 1. 결함 재현 (수정 전)

`journal_recall`은 FTS5 **접두 질의**로 후보를 뽑은 뒤(`_fts_match_query`가
`"포지"*` 형태로 만든다), 파이썬에서 **완전일치 토큰 교집합**으로 다시
점수를 매겼다. 그래서 인덱스가 방금 찾아낸 턴을 재점수 단계가 도로
버렸다. 임시 DB 실측:

| 질문 | 저장된 턴 | 수정 전 |
|---|---|---|
| `포지 기억나?` | `포지야 오늘 방송 재밌었어` | **[] (회상 0건)** |
| `포지야 기억나?` | 〃 | 회상 성공 |
| `별명 기억나?` | `어제 얘기한 별명은 반짝이야` | 회상 성공 |

`별명`이 되는 이유는 조사 목록(`_KOREAN_JOURNAL_PARTICLE_RE`)에 `은`이
있어 어간이 복원되기 때문이다. 호격 `야`처럼 목록 밖 굴절은 전부 이
구멍에 빠진다 — 즉 조사 목록을 늘리는 것은 임시방편이고, 랭킹 자체를
FTS에 맡기는 것이 정공이다.

## 2. 수정

`ollama-proxy/airi_memory.py`:

1. FTS 분기에서 매치된 메시지의 **`bm25(conversation_message_fts)` 랭크**를
   같은 경계값(`JOURNAL_FTS_CANDIDATE_MESSAGES`, `journal_fts_start_id`)으로
   한 번 더 조회한다.
2. 행 SELECT에 `message.id`를 추가해 랭크를 턴에 붙일 수 있게 했다
   (FTS 없는 분기도 열 구성을 맞춘다).
3. 점수 계산:

```python
strength  = max(-rank)  # bm25는 음수·작을수록 좋음
relevance = strength / (1 + strength)      # (0,1)로 접음
score     = float(overlap) if overlap else relevance
```

**완전일치가 있는 턴은 종전 그대로 정수 점수**를 쓰므로 기존 순위와
최근성 tiebreak가 바뀌지 않는다. 접두만 맞은 턴은 (0,1) 점수로 들어와
**모든 완전일치 턴보다 아래**에 놓인다. 즉 이번 변경은 순위 재배열이
아니라 **버려지던 후보의 복구**다.

> 설계 이력: 처음에는 `overlap + relevance`로 합산했더니
> `test_journal_recall_window_is_4096_messages`가 깨졌다 — 같은 overlap
> 안에서 bm25가 최근성을 눌러 최신 턴이 밀려났기 때문이다. 회상 창의
> 최근성 계약을 유지하려면 **bm25는 overlap이 0일 때만** 쓰는 것이
> 맞다. (실패한 시도와 이유를 남긴다.)

FTS5가 없는 SQLite 빌드에서는 `ranks = {}`라 종전 동작과 **바이트 동일**하다.

## 3. 실측

수정 후 같은 재현 스크립트:

| 질문 | 수정 후 |
|---|---|
| `포지 기억나?` | `['포지야 오늘 방송 재밌었어', '나도 즐거웠어!']` ✅ |
| 나머지 3종 | 종전과 동일(회귀 없음) |

**지연**(`benchmark_memory_track.py --mode journal-recall --retrieval-runs 30`,
10,000행 임시 DB, 동일 머신 연속 측정):

| | p50 | p90 | p95 | 게이트 |
|---|---:|---:|---:|---|
| 수정 전 | 5.457 ms | 5.679 ms | 5.728 ms | pass (≤150ms) |
| 수정 후 | 6.859 ms | 7.460 ms | 7.779 ms | pass (≤150ms) |

랭크 조회 1회가 늘어 **p50 +1.4ms**다. 게이트 상한 150ms 대비 5% 수준이라
그대로 둔다(지연 예산 여유 > 코드 복잡도). 이 픽스처는 전 행이 완전일치라
추가 회상은 나타나지 않고 **비용만** 드러나는 보수적 측정이다.

## 5. 남은 것 / 한계

- 이번 변경은 **어휘 랭킹만** 고친다. 컨텍스트 게이트의
  `dialogue_marker 0/12`는 회상 경로 외에 전경 투영 상한(5개)·추출 OFF
  원인이 함께 있으므로 이 한 건으로 해소되지 않는다(리서치 §2-3).
  게이트 재실행 대조는 별도 배치로 남긴다.

  있다. 완전일치 턴이 항상 우선이므로 상한이 찬 경우 영향은 없다.
- `unicode61` 토크나이저 기준이라 한국어 형태소 분석은 여전히 없다.
