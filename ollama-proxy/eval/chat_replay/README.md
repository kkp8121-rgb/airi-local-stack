# Privacy-preserving local chat replay

This directory evaluates AIRI against the *structure* of Korean livestream chat: event order, relative timing buckets, duplicates, noise, and donation-callout semantics. It is local-only. The importer has no provider SDK, OAuth, persistence, network access, or sleeping path; a local model request requires an explicit literal-loopback `--loopback-url`.

Real captures belong only in the ignored `local-replay-intake/` directory, and the CLI rejects export, consent, or provenance paths outside it or through a reparse point. Each platform-neutral JSONL export needs both an adjacent consent sidecar and the separate local written-authorization/custody record named by `--provenance`. The sidecar binds the exact export and provenance bytes through their SHA-256 values, must explicitly authorize `local_replay_evaluation`, must not be revoked, and must not be expired. This proves that the operator supplied the same local evidence artifact; it does not cryptographically authenticate its issuer, so a human must still verify the permission. Missing, malformed, altered, expired, or revoked inputs fail closed.

The JSONL importer requires `timestamp_ms`, `kind` (`chat`, `donation`, or `noise`), and `text`. It accepts only the documented platform-neutral identity-field allowlist and rejects unknown fields. It removes those metadata fields from model events and uses their values only as one-pass redaction targets, then redacts display/creator names declared in the sidecar, profile links, URLs, `@handles`, email addresses, phone numbers, Korean resident-registration-number-shaped strings, unsafe Unicode, and donation amounts before a model callback can receive text. Automation covers only these explicit identifiers and structured patterns; a human privacy review is mandatory before model opt-in. It returns the resulting private replay only in memory. Reports contain counts, timing buckets, duplicate counts, and one structural hash—never raw chat, redacted chat, identities, or response text.

The sidecar is a local-only JSON object with exactly `schema_version`, `authorization`, `authorization_basis`, `authorized_at`, `purposes`, `expires_at`, `delete_by`, `revoked`, `source_sha256`, `provenance_sha256`, and `excluded_creator_names`. `authorization_basis` is either `creator_or_platform_written_permission` or `operator_owned_broadcast`; a public watch page alone is neither. `provenance_sha256` binds the separate local custody/permission record. `excluded_creator_names` contains local redaction terms and therefore the sidecar must never be committed.

Committed fixtures are independently authored synthetic material. They preserve replay behaviors but are not anonymized real chat and are not training data. `replay-suite-manifest.v1.json` pins their bytes and the deterministic Mi:dm evaluation profile. Named-creator imitation, source-style matching, and viewer memory are not goals of this evaluator.

Example (outputs should stay ignored):

```powershell
python .\run_chat_replay.py --input .\local-replay-intake\capture.jsonl --consent .\local-replay-intake\capture.consent.json --provenance .\local-replay-intake\capture.permission.txt --report .\reports\capture-report.json
```

Use `--loopback-url http://127.0.0.1:11435/v1/chat/completions --model midm-airi:2.0-mini` only for an explicitly approved local experiment. No raw Ollama port or remote endpoint is accepted. Before and after every replayed turn as well as the full run, the runner verifies the frozen Mi:dm tag and exact pinned/verified digest in the suite manifest, `num_ctx=2048`, and the expected epistemic-confidence state (default `on`; `--expected-epistemic-confidence off` is an explicit A/B assertion and does not change the service). It sends `temperature=0`, `seed=42`, `max_tokens=128`, and keeps a bounded eight-turn dialogue history so ordering and callbacks reach AIRI reproducibly. The content-free report stores the attested profile plus response hashes and lengths. To inspect the actual redacted input/response pairs, explicitly add `--private-review-output .\private-replays\capture-review.json`; this separate packet is local-only and ignored and is unavailable in offline structure-only mode. Both output paths are restricted to their ignored non-reparse directories and revalidated at write time. Run this only as an exclusive local operator session: a hostile process that swaps the model or Windows junctions between checks is outside this filesystem custody boundary. The default run makes no network request.
