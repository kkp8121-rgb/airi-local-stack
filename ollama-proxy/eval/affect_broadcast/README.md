# Synthetic affect broadcast evaluation

This is the A4 synthetic-only offline foundation and transport contract: six independently authored Korean broadcast-flow scenarios with 24 continuous turns each. The turns preserve distinct AIRI speech, screen/game state, selected viewer chat, no-response moments, and a canonical typed affect event. They cover first-broadcast warming, teasing and repair, repeated game failure and recovery, correction and admission, callback/donation/noise, and fatigue with safety precedence.

The model request keeps the selected viewer chat as the latest plain `user` utterance. The current synthetic screen/topic observation is a coalesced request-local system note shared byte-for-byte by both arms; only the typed affect snapshot is appended in the ON arm. This separation prevents descriptive screen words such as “확인” or “저장” from being misclassified as viewer requests for an unexecuted external action.

The evaluator checks the closed reducer oracle, exact scenario/event manifests, bounded fixed multi-turn history, OFF/ON request pairing, and safety/repair structure. It is not a completed Mi:dm A/B evaluation and does not score model quality; causal expression, continuity, positivity collapse, repair quality, safety/privacy, and character specificity require blind human review. Character specificity remains explicitly unscored until the A0 constitution is approved.

The default command performs no network work. Optional execution is transport-injected and accepts only `http://127.0.0.1:11435/api/chat` with `x-airi-turn-origin: local-evaluation`. It freezes the Mi:dm tag/digest, `num_ctx`, temperature, seed, token limit, history bound, and operational affect gate OFF through pre/post health evidence. Every arm uses the same canonical fixture history; the ON arm adds only the bounded request-local continuity note. Unselected no-response turns never call the model. Failed HTTP/JSON, empty output, incomplete pairs, or profile drift fail closed.

The default CLI deliberately stays offline. An explicit local run uses `--execute --output-dir ollama-proxy/eval/affect_broadcast/local-results/<fresh-name>` and only the literal `http://127.0.0.1:11435/api/chat` endpoint. It disables environment proxy use, rejects redirects, bounds request/response bodies to 64 KiB, applies request and overall deadlines, performs pre/post health checks, and makes exactly 122 OFF/ON pairs (244 POSTs) after the health check succeeds. Deadline checking around response reads is cooperative: a blocking socket read is limited by its per-request timeout, then the monotonic overall deadline is checked before and after every received chunk. It never starts a model, changes an environment variable, calls cloud endpoints, mutates the production affect runtime, or authorizes operational adoption.

Public reports contain only aggregate paired counts and total response characters, never arm-specific response metadata. Before any model call the runner reserves a safe ASCII run name under `local-results/` and its matching operator key path. A completed run atomically publishes the report and blinded packet to `local-results/`; the arm key is published separately under ignored `local-operator-keys/<run-name>.json`. The receipt does not bind or hash the key, because its two mappings are enumerable. Key-first publication is rolled back on ordinary failures before review publication; power loss and hostile-local-machine integrity remain outside this mechanism's guarantees.

This foundation uses independently authored synthetic chat only. It is separate from the authorized 30–120 minute real-chat replay campaign and from installed AIRI→11435→TTS evidence. Operational `AIRI_AFFECT_CONTINUITY_ENABLED` remains default OFF, and neither offline oracle success nor a future A/B result automatically adopts it.

The proxy trusts the evaluation request-local note only for an exact loopback `local-evaluation` turn and only when the note matches the closed broadcast-context grammar plus, for the ON arm, the production-rendered affect snapshot byte-for-byte. The selected viewer utterance remains the user message; screen/topic metadata never becomes user text or an Active Character Card. Arbitrary prefixed prompts, extra keys, noncanonical JSON, unsafe Unicode, and malformed affect snapshots are dropped.

The first valid local Mi:dm run (`run-20260817-midm-03`) completed 122 pairs/244 responses and was reviewed while arm labels were blinded. After review, A mapped to OFF and B to ON. ON did not improve the causal, continuity, repair, safety, or fallback gates, so operational adoption remains rejected pending a grounded closed-schema reply-act realization experiment.
