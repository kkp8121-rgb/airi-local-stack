# vod_capture_2026-08-27 — 공개 VOD 1편 수집 자산

2026-08-27 클로드 PC 에서 공개 VOD 1편을 수집해 만든 평가 자산이다. **다른 PC 가 그대로 쓸 수
있도록 저장소에 둔다** — 재수집하면 HMAC 키가 달라져 가명이 바뀌고 STT 도 완전히 같지 않아,
양쪽 자산이 갈라진다.

## 계약 §1 예외 기록

계약 §1 은 "실제 대화 본문·시청자 식별 정보를 Git·문서·채팅에 넣지 않는다" 고 한다.
**이 디렉터리는 그 조항의 명시적 예외이며 2026-08-27 사용자 결정이다.** 근거와 경계:

- 저장소는 **private** 이다.
- 시청자 표시명·채널 ID·userIdHash 는 없다. `author` 는 HMAC-SHA256 가명(`v`+8자)뿐이다.
- **가명화 키(`hmac.key`)는 넣지 않는다.** 키가 있으면 가명을 되돌릴 수 있다.
- **가명화 이전 원본(`raw-*.json`, 14.5MB)은 넣지 않는다.** `userIdHash` 가 그대로 들어 있다.
- **오디오(m4a 90MB · wav 58MB)는 넣지 않는다.** 원 저작물이고 git 에 담을 물건도 아니다.
- 용도는 **로컬 평가 한정**이다(맥락 주입 · 채점 기준점 · 픽업 정답지). **학습 정답으로 쓰지
  않는다** — 타인 페르소나 학습은 캐릭터 헌법과 충돌하고 권리 문제도 별개다.

## 이 자산으로 알아낸 것

`airi_docs/진행중/AIRI-EVAL-INPUT-CONTEXT-AUDIT-2026-08-27.md` §4-3·§4-4 참조. 요지:

- 스트리머가 반응한 57건 중 **80.7% 가 question 이 아니다**(질문 선호는 1.7배뿐). 현행 픽업 정책은
  77건 중 75건을 질문으로 채운다.
- 픽업 정책 변형 4종 적중률: 현행 7.0% / `reaction` 승격 **0.0%** / cooldown 10s 5.3% /
  stale 300s 3.5%. 점수제 이식도 최고 8.8%(5건 vs 4건)로 개선이 없어 **픽업 트랙은 종료**했다.
- 적중률 7% 는 **절대 성능이 아니다.** 정답지 57건은 하한이다 — 어휘를 겹치지 않고 답한 경우
  ("응 맞아")는 탐지되지 않는다. **정책 간 상대 비교로만 유효하다.**
