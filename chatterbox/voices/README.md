# AIRI reference voice

Copy the user-owned Korean character voice recording here as:

`airi-reference.wav`

Recommended source:

- One speaker, Korean, approximately 5-15 seconds
- Clean speech without music, effects, reverb, or clipping
- Natural acting close to the intended AIRI character
- WAV preferred; mono or stereo is accepted

Then run `start-local-tts.ps1`, followed by `generate-exaggeration-samples.ps1`.
